What are the 3 Hard Theorems?

The 3 Hard Theorems are three theorems about continuous functions on closed intervals

The Theorems in Question

  1. Intermediate Value Theorem

    If f is continuous on [a,b] and f(a) < 0 < f(b), then there is a c in (a,b) such that f(c) = 0.

  2. Boundedness Theorem

    If f is continuous on [a,b], then f is bounded on [a,b]. In other words, an upper bound and a lower bound exist.

  3. Extreme Value Theorem

    If f is continuous on [a,b], then f has a maximum and a minimum on [a,b].
